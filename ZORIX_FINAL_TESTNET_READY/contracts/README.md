# Contracts placeholder
This package intentionally does not include a production fund-custody or guaranteed-return staking contract.

Before deploying any contract that can receive user assets:
- define exact token economics and withdrawal rules
- obtain legal/compliance advice for the target jurisdictions
- write comprehensive unit/integration tests
- deploy to a public testnet first
- obtain an independent security review/audit
- use a multisig/timelock for privileged production operations

Never paste private keys or seed phrases into the web app or repository.
